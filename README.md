# ROCKET DEANON PRO

**Инструмент для сбора информации по Telegram-юзеру, номеру телефона и IP-адресу.**  
Включает функцию массовых жалоб (снос) для Telegram.

---

## 📌 ВОЗМОЖНОСТИ

| Команда | Что делает |
|---------|------------|
| `telegram` | Полная информация по юзеру: ID, имя, номер (если найден), описание, фото, ссылки на соцсети |
| `number` | Полная информация по номеру: страна, оператор, проверка утечек, привязка к соцсетям, местоположение |
| `ip` | Полная информация по IP: город, регион, провайдер, ASN, координаты, карта, проверка на VPN/прокси |
| `snos` | Снос цели в Telegram: 20 жалоб за 10 минут |
